How Pickle ruins your day

Touches all your stuff

Finder, Spotify, Messages, Contacts, your browser, your windows, your cursor. Pickle uses your Mac the same way you do.

Chaotic, not reckless

Adopt Pickle in two minutes

macOS 14+, Xcode 15+, Python 3 and XcodeGen. A Featherless API key makes the roasts smarter.

Terminal
# clone and install
git clone https://github.com/matesuu/Decisions.git
cd Decisions
python3 -m pip install -r sidecar/requirements.txt

# secrets (never commit this)
echo "FEATHERLESS_API_KEY=your-key" >> ~/.chaos_tamagotchi.env
echo "CHAOS_TEXT_ALLOWLIST=Friend Name" >> ~/.chaos_tamagotchi.env

# build and run
cd DesktopApp && xcodegen generate
xcodebuild -scheme ChaosTamagotchi -derivedDataPath build build
open build/Build/Products/Debug/ChaosTamagotchi.app

Frequently asked questions

Will it text my mom?

Only if your mom is in CHAOS_TEXT_ALLOWLIST. It defaults to a single test contact, and texts are signed by the pet, never pretending to be you or a relative.

How do I make it stop?

Choose Restore Everything from the menu bar to undo everything it did, or turn on Safe Mode so it just roams and says cute things. Clicking Pickle feeds it 15%; above 85% its automatic calm tier is harmless too. Quit is in the same menu.

What's an ultimatum?

Before a severe crime, Pickle sometimes offers two and gives you eight seconds to pick one. Ignore it and it does both. Some are fake-outs: two outrageous threats, then "jk" and one giant poop.

Does it need an API key?

No. Without a Featherless key it uses canned notes and built-in texts. With one, the sticky notes and messages are written by an LLM.

What permissions does it ask for?

Accessibility for window shoving, and Automation for Finder, Contacts, Messages and Spotify. macOS prompts the first time each one is used.

Windows? Linux?

Mac only. Pickle is deeply attached to AppleScript.
